# YouTubeDubbingQ

YouTube 视频 AI 双语字幕翻译 + 实时中文配音 Chrome 扩展插件。

## 功能特点

- 🔤 **双语字幕**：自动获取 YouTube 视频英文字幕，通过 AI 翻译为精炼中文，以 Netflix 风格显示双语字幕
- 📜 **中英对照逐字稿面板**：
  - 🎥 随视频播放**自动高亮当前句**并平滑跟播滚动
  - 🔍 内置**中英文全文实时搜索**、关键词高亮与上下匹配项跳转
  - ⏱️ 点击时间戳或字幕行**一键跳播**定位
  - 📐 浮动面板支持**自由拖拽**与**尺寸拉伸**，自动记忆窗口坐标与尺寸
- 🚀 **智能优先队列调度器 (TranslateScheduler)**：
  - 🎯 **播放点优先**：当前视频播放点所在片段最高优先级（零等待）
  - ⏩ **前方缓冲**：即将播放的字幕排在前方，快进/跳播自适应重排
  - 🔄 **Tier-0 失败优先重试**：网络或解析异常优先重试，彻底消除字幕“开天窗”
- 🖱️ **沉浸式播放器直接交互**：
  - 🖐️ 鼠标直接**拖拽字幕框**定位（以播放器百分比存储，全屏切换无缝适配）
  - 🎡 字幕框上**鼠标滚轮直接缩放字号**（中英双语联动调整）
  - ⌨️ 键盘 **`C` 键快捷键**一键开关双语字幕
  - 🔄 双击字幕框快速复位默认位置
- 💾 **双语 SRT 导出**：
  - 严格进度检查与提示，一键导出中英双语对齐的标准 `.srt` 字幕文件
- 🎙️ **实时配音**：支持 Edge TTS 和豆包 TTS 两种配音引擎，实时中文配音
- 🔊 **智能音量控制**：配音时自动降低原视频音量，保留背景音乐
- ⚡ **音画同步**：AI 翻译长度约束 + TTS 动态调速，确保配音与画面精确对齐
- 🤖 **OpenAI 兼容**：支持任何 OpenAI 兼容的 AI 服务（本地 LLM、豆包、深度求索、DeepSeek 等）

## 安装方法

1. 克隆或下载此仓库：
   ```bash
   git clone https://github.com/qxk2005/YouTubeDubbingQ.git
   ```

2. 打开 Chrome 浏览器，进入 `chrome://extensions/`

3. 开启右上角的 **开发者模式**

4. 点击 **加载已解压的扩展程序**

5. 选择 `YouTubeDubbingQ` 文件夹

6. 扩展图标出现在浏览器工具栏中 ✅

## 使用方法

### 1. 配置 AI 翻译服务
- 点击扩展图标，在 **API 设置** 标签中：
  - 输入 OpenAI 兼容服务器地址（如 `https://api.openai.com` 或第三方代理地址）
  - 输入 API Key
  - 输入模型名称（如 `gpt-4o-mini`、`deepseek-chat` 等）
  - 点击「测试连接」确认配置正确

### 2. 启用双语字幕与快捷交互
- 打开任意 YouTube 视频
- 视频播放器右下角会出现 YouTubeDubbingQ 悬浮工具栏
- 点击 🔤 字幕按钮（或直接按下键盘 **`C`** 键）启用双语字幕
- 在播放器字幕框上：
  - **按住左键拖拽**：随心移动字幕到画面任意位置
  - **滚动鼠标滚轮**：即时微调字幕大小
  - **双击字幕框**：恢复默认底部居中位置

### 3. 打开中英对照逐字稿
- 在工具栏中点击 📜 **逐字稿** 按钮
- 逐字稿面板会自动跟随播放进度滚动高亮
- 在搜索框中输入关键词，可快速定位视频重点片段并点击跳播

### 4. 导出双语 SRT 字幕
- 点击工具栏或逐字稿面板顶部的 💾 **导出 / SRT** 按钮
- 即可下载包含中英双语对齐的标准 `.srt` 字幕文件

### 5. 启用实时中文配音
- 在工具栏中点击 🔊 配音按钮
- 配音会自动跟随视频进度流畅播放

## 配音引擎

### Edge TTS（免费）
- 无需 API Key，直接使用微软 Edge 语音服务
- 支持多种中文语音（男声/女声）
- 适合日常使用

### 豆包 TTS
- 需要配置豆包 API Key
- 通过 OpenAI 兼容接口调用
- 音质更好，语音更自然

## 技术栈

- Chrome Extension Manifest V3
- 纯原生 HTML5 / CSS3 / JavaScript（无编译打包负担）
- YouTube timedtext API
- OpenAI 兼容 Chat API
- TranslateScheduler 优先队列排程算法
- Edge TTS WebSocket
- Web Audio API
